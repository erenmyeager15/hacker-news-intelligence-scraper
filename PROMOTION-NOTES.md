## 60-Second Tutorial Script

1. Open the Actor and keep `mode` as `feed`.
2. Select the `top` or `show` feed and set `maxResults` to 10.
3. Run without comments for a quick first dataset.
4. Show title, URL, domain, score, comments, author, and HN discussion URL.
5. Mention that nested comments can be enabled for smaller runs.
